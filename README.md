# 문해력 15분

특성화고(상업계열·보건행정·3D애니메이션) 학생을 위한 하루 15분 문해력 학습 웹앱입니다.
32주(주 1주제, 총 32주제 · 160일) 커리큘럼과 학생별 학습 기록(구글 시트 연동)을 제공합니다.

## 폴더 구조

```
index.html            앱 화면 뼈대
css/style.css          스타일 (라이트/다크 모드 포함)
js/config.js           구글 시트 연동 URL 등 설정
js/auth.js              학생 로그인(학년·반·번호·비밀번호)
js/admin.js              관리자(담임) 설정 — 학생 비밀번호 초기화
js/sync.js               학습 기록을 구글 시트로 전송
js/app.js                라우팅·화면 렌더링·채점 로직
data/curriculum.js       32주 커리큘럼 뼈대(주제·요일 자동 생성, 새 형식 주차 목록 포함)
data/content/wXX.js      주차별 실제 학습 콘텐츠(단어·문제·지문)
gas/Code.gs               구글 시트 쪽에 붙여넣는 Apps Script 코드
```

## 로컬에서 열어보기

`index.html`을 브라우저로 더블클릭해서 열면 바로 동작합니다(별도 서버 불필요).

## 콘텐츠 추가하는 법

주차는 **32주 · 주 1주제 · 하루 1회차(5일)** 입니다. 회차 구성은 두 가지 형식이 있습니다.

| 형식 | 적용 주차 | 1~2일차 | 3일차 | 4일차 | 5일차 |
| --- | --- | --- | --- | --- | --- |
| 기존 | 1주차, 16주차 이후 | 어휘 6개 + 확인문제 3개 (+헷갈리는 어휘) | 확인① | 확인②(읽기 적용) | 종합복습 + 명언 |
| **새 형식** | **2~15주차**(앞으로 순차 적용) | **어휘 8개** + 확인문제 4개 | **어휘 8개 + 확인문제 4개** | **종합점검**: 어휘 단위 50% + 문장 지문 50% | **새 문장 복습** + 돌아보기·다음 주 계획 |

새 형식은 한 주에 어휘 24개를 배우고, 4일차에 24개를 낱말·지문 두 방식으로 점검하며, 5일차에는 처음 보는 문장에서 다시 확인합니다.
매일 **"나의 계획·마음 한 줄" 카드**(점수와 무관)가 붙습니다: 1일차 이번 주 목표 세우기 → 2일차 어제 목표 점검 → 3일차 중간 신호등 → 4일차 다시 볼 낱말 → 5일차 한 주 돌아보기·다음 주 목표(+ 주제와 이어지는 활동: 2주차 용돈 계획표, 3주차 계약·결제 전 확인, 4주차 정보 퍼뜨리기 전 확인, 5주차 아르바이트·취업 전 확인, 6주차 판매·홍보 계획 전 확인, 7주차 병원에 가기 전 확인, 8주차 영상·디자인 공개 전 확인, 9주차 함께 사는 사회를 위한 실천, 10주차 시민으로서의 확인, 11주차 계약·분쟁 앞에서의 확인, 12주차 역사를 만날 때의 확인, 13주차 탐구·발표 전 확인, 14주차 지구를 위한 실천, 15주차 작품을 만날 때의 확인 체크리스트).
**마음 한 줄은 요일 테마가 매주 고정**이고 문구만 주차마다 새로 씁니다: 1일 나에게 친절 / 2일 감사 / 3일 실수 받아들이기 / 4일 친구 칭찬 / 5일 돌아보기. (카드 제목 끝의 괄호가 테마입니다.)
학생이 적은 내용은 **그 학생의 기기(localStorage)에만** 저장되고 서버·선생님께 전송되지 않습니다.

### 새 형식 주차를 만드는 순서

원본은 **`worksheets/weekNN_data.py` 한 파일**이고, 여기서 앱 콘텐츠와 학습지가 함께 만들어집니다(앱·학습지 문항이 어긋나지 않게).

1. `worksheets/week15_data.py`(또는 week02~14)를 복사해 `weekNN_data.py`로 만들고 내용을 채웁니다. (낱말 24개, 확인문제 12개, 4·5일차 문항, 지문 2개, 계획·마음 카드 — extras 종류: plan·money·check·checklist·mind)
2. `data/curriculum.js`의 `NEW_FORMAT_WEEKS` 배열에 주차 번호를 추가합니다.
3. `worksheets`에서 실행합니다. (`weekNN_data.py`를 자동으로 찾습니다. 한 주차만: `--week N`)
   - `python generate_v2.py` → `data/content/wNN.js` + 학습지 docx·PDF 생성. 하루 학습지가 **A4 1쪽이 아니면 오류로 멈춥니다**(저장소 폴더에는 1쪽이 아닌 파일을 넣지 않음).
   - PDF 변환에는 Microsoft Word(윈도우)가 필요합니다. 처음 뜨는 "기본 프로그램으로 설정할까요?" 확인창은 스크립트가 자동으로 "아니요"를 누릅니다.
4. `python merge_pdfs.py` → `전체_학습지_모음(1-32주차).pdf`를 최신으로 다시 합칩니다.
5. 필요한 경우 `index.html`에 `<script src="data/content/wNN.js"></script>`가 있는지 확인합니다. (1~32주차는 이미 연결되어 있음)

기존 형식 주차의 학습지는 `worksheets/generate.py`(주차 데이터가 이 파일 안에 있음)로 만듭니다. 새 형식으로 옮긴 주차는 이 파일의 `__main__`에서 빠져 있습니다.
`data/content/wNN.js`(새 형식 주차)는 자동 생성 파일이므로 직접 고치지 말고 `weekNN_data.py`를 고친 뒤 다시 생성하세요.

콘텐츠가 없는 날짜는 사이드바에 "준비 중"으로 표시됩니다.

## 구글 시트 연동 설정 (학생 학습 기록 자동 저장)

설정하지 않아도 앱은 정상 동작하며, 기록은 학생 기기(브라우저)에만 저장됩니다.
전체 학생 기록을 한 곳(구글 시트)에 모으려면 아래 절차를 따르세요.

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만듭니다. (예: `문해력15분_기록`)
2. 상단 메뉴 **확장 프로그램 → Apps Script**를 클릭합니다.
3. 열린 편집기의 코드를 모두 지우고, 이 저장소의 [`gas/Code.gs`](gas/Code.gs) 내용을 그대로 붙여넣습니다.
4. 저장(Ctrl+S) 후 우측 상단 **배포 → 새 배포**를 클릭합니다.
5. 유형에서 **웹 앱**을 선택하고,
   - 실행 계정: **나(내 계정)**
   - 액세스 권한: **모든 사용자**
   로 설정한 뒤 **배포**를 누릅니다. (처음 한 번은 구글 계정 권한 승인 화면이 나옵니다.)
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/....../exec`)을 복사합니다.
7. 이 저장소의 `js/config.js` 파일을 열어 아래처럼 URL을 붙여넣고 저장·커밋·푸시합니다.

   ```js
   const APP_CONFIG = {
     SHEET_WEBAPP_URL: "여기에_복사한_웹앱_URL_붙여넣기",
     SCHOOL_NAME: "명품 경북여상 문해력 15분",
   };
   ```

8. 이후 학생이 학습을 완료할 때마다 스프레드시트의 **"기록"** 시트에 자동으로 한 줄씩 쌓입니다.
   (기록시각, 학번코드, 학년, 반, 번호, 이름, 주차, 일자ID, 영역, 주제, 유형, 점수)

> URL 설정 전에 이미 학습한 기록은 학생 기기에 "대기열"로 저장되어 있다가, URL이 설정된 이후 접속하면 자동으로 전송됩니다.

### 학생용 "내 점수 기록" 보기

화면 오른쪽 위 프로필 옆 **📊 아이콘**을 누르면 학생 본인의 점수 기록(날짜·주제·유형·점수, 평균, 꺾은선 그래프)을 볼 수 있습니다.
`SHEET_WEBAPP_URL`이 설정되어 있으면 구글 시트에서 전체 이력을 불러오고, 설정 전이거나 통신이 안 되면 이 기기에 저장된 최근 점수만 대신 보여줍니다.
(`gas/Code.gs`를 그대로 다시 배포하면 `doGet`이 `?studentId=` 조회를 지원하도록 자동으로 갱신됩니다. 이미 배포한 뒤 이 파일을 업데이트했다면 **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전**으로 다시 배포해야 반영됩니다.)

### 금요일 "위클리 행운아" 이벤트

매주 금요일 아침, **그 주(월~금) 5일 학습을 모두 08:30~08:45 사이에 완료한 학생** 중 **반마다 1명**을 무작위로 뽑는 기능입니다.
자격자가 없는 반은 **X**로 기록됩니다(테스트 반은 뽑지 않습니다). 결과는 화면 오른쪽 위 **🎉 아이콘**(학생)과 마스터 화면의 **🍀 위클리 행운아** 메뉴(주차별 표)에서 볼 수 있고,
담임 선생님이 명단을 보고 칭찬카드를 발급하는 식으로 활용하시면 됩니다.

1. `gas/Code.gs`를 최신 버전으로 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 재배포합니다. (URL은 그대로 유지됩니다.)
2. Apps Script 편집기 상단에서 함수 선택 드롭다운을 **`installWeeklyTrigger`**로 바꾸고 ▶ **실행**을 한 번만 눌러주세요. (최초 실행 시 권한 승인 창이 뜰 수 있어요.) 이 작업으로 "매주 금요일 오전 8시 50분쯤 자동 추첨"이 예약됩니다. 이미 실행했다면 다시 할 필요가 없습니다.
3. 이후 매주 금요일 아침, 스프레드시트의 **"위클리행운아"** 시트에 추첨일마다 **반당 한 줄**이 기록됩니다(당첨자가 있으면 학번·이름, 없으면 이름 칸에 `X`).
   예전 이름의 **"행운의7명"** 시트가 있으면 처음 불러올 때 이름만 "위클리행운아"로 바뀌고 기존 기록은 그대로 이어집니다. (예전에는 전교 7명을 뽑았으므로, 그 주차는 마스터 표에서 당첨된 반에만 이름이 보이고 나머지 반은 `-`로 나옵니다.)
4. 마스터 화면 **🍀 위클리 행운아**: 학년별로 반을 열, 주차("11월 1주차" — 추첨 금요일이 속한 달에서 몇 번째 금요일인지)를 행으로 보여 주고, 같은 학생이 또 뽑히면 이름 옆에 횟수를 적습니다(예: `김나은(3회)`, 첫 번째는 표시하지 않음). CSV로 내려받을 수 있습니다.

#### 행운아 알림 (학생·담임·교사 단톡방)

추첨이 끝나면 별도 설정 없이 다음처럼 알려집니다. (서버에 `?luckyNotice=1&studentId=` 조회와 `adminStatus`의 `lucky` 항목이 추가되어 있어, `gas/Code.gs`를 재배포하면 적용됩니다.)

| 대상 | 알림 |
| --- | --- |
| **행운아 본인** | 앱을 열면 🎉 "축하해요! 이번 주 위클리 행운아는 바로 너예요!" 팝업(몇 번째 행운아인지, 담임 선생님께 칭찬카드를 받으라는 안내) |
| **대상자였지만 미당첨** (5일 모두 08:30~08:45 완료) | 🍀 "이번 주 우리 반 위클리 행운아"(이름·횟수) + "너도 추첨 대상자였어요, 다음 주에도 도전해요" |
| **미대상자** (이번 주 5일을 채우지 못함) | 🍀 우리 반 행운아 + "이번 주는 기록이 없어요/N일 완료, 다음 주에 도전" 안내 |
| **자격자가 없는 반** | "이번 주는 우리 반 행운아가 없어요" 격려 안내 |
| **담임 선생님** | ⚙️ 관리자 설정에서 학년·반을 입력하면 맨 위에 우리 반 행운아 배너(최근 5주 이력 포함)와 명단의 🍀 표시 |
| **교사 단톡방** | 마스터 **🍀 위클리 행운아** 화면의 **발표문 복사** 버튼 → 학년·반별 당첨자 한 덩어리 문구를 복사해 붙여넣기 |

- 학생 팝업은 **같은 추첨은 학생(기기)마다 한 번만** 뜨고, 확인을 누르면 다시 뜨지 않습니다. 팝업에서 **전체 행운아 보기**를 누르면 전교 목록(🎉)이 열립니다.
- 금요일 추첨(약 8:50)은 학생들이 학습하는 시간(8:30~8:45) 이후라, 대부분 **다음 학습일(월요일)에 앱을 열 때** 팝업을 보게 됩니다.
- 처음 가입하며 비밀번호를 설정한 그 세션에서는 팝업을 건너뜁니다. 테스트 반은 팝업이 없습니다.
- 학생 응답에는 본인의 이번 주 완료 일수만 포함되고, 다른 학생의 학번·기록은 포함되지 않습니다.

> 인정 시간대(08:30~08:45)를 바꾸고 싶으면 `gas/Code.gs` 상단의 `DAILY_START`, `DAILY_CUTOFF` 값을 수정한 뒤 다시 배포하세요. 뽑는 인원은 "반마다 1명"으로 고정입니다.
> 정확한 시각 판정을 위해 스프레드시트의 시간대가 **한국 표준시(서울)**로 설정되어 있는지 확인해 주세요. (스프레드시트 메뉴 **파일 → 설정 → 시간대**)
> 월~금 중 휴일이 끼면 "5일 모두 완료"를 채울 수 없어 그 주는 모든 반이 X가 됩니다. 이런 주는 따로 처리해야 합니다.

### 학생별 요약을 보고 싶다면

"기록" 시트 옆에 새 시트를 만들고 다음과 같은 `QUERY` 수식으로 학생별 완료 횟수·평균 점수를 집계할 수 있습니다.

```
=QUERY(기록!A:L, "select B, F, count(H), avg(L) where L <> '' group by B, F label count(H) '완료수', avg(L) '평균점수'", 1)
```

## 학생 로그인 방식

**학년 + 반 + 번호 + 비밀번호**로 로그인합니다. (예: 1학년 1반 2번 → 학번코드 `1102`)
로그인 정보는 학생 기기의 브라우저에만 저장되며, 다른 학생으로 전환하려면 화면 오른쪽 위 프로필을 눌러 "다른 학생으로 전환"을 선택하면 됩니다.

`SHEET_WEBAPP_URL`이 설정되어 있지 않으면(개발/테스트) 예전처럼 대조 없이 통과됩니다.
설정되어 있으면 아래의 **명렬 대조 + 비밀번호 로그인** 방식이 적용됩니다.

## 마스터(admin) — 전교 출결 대시보드

학교 전체 학생의 출결 현황을 한 화면에서 보는 마스터 계정입니다. 로그인 화면(또는 사이드바)의 **⚙️ 관리자 설정 → "🛡️ 마스터(전교 출결 보기)로 들어가기"**에서 아이디·비밀번호로 들어갑니다.

- **설정 (한 번만)**: Apps Script 편집기 → 왼쪽 ⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가
  - `MASTER_PASSWORD` = 마스터 비밀번호 (**이 속성이 없으면 마스터 로그인이 막혀 있습니다**)
  - `MASTER_ID` = 아이디 (선택, 비워 두면 `admin`)
  - 비밀번호는 코드나 시트가 아니라 이 속성에만 저장합니다. 공개 저장소에는 절대 적지 마세요.
- **보안**: 비밀번호를 5번 틀리면 10분 동안 잠깁니다(담임용 관리자 비밀번호는 따로 셉니다). 마스터 비밀번호는 기존 "관리자 설정"(학생 비밀번호 초기화)에서도 관리자 비밀번호로 통합니다. 입력한 아이디·비밀번호는 화면이 열려 있는 동안 메모리에만 있고 저장되지 않습니다.
- **출결 기준**: 그날 학습을 **완료**했으면 "완료", 접속만 했으면 "접속만", 기록이 없으면 "미접속"입니다.
- **볼 수 있는 것**: 전교·학년·반별 완료/접속만/미접속 인원과 완료율, 학생별 월~금 출결(★ = 08:30~08:45 안에 완료 → 위클리 행운아 자격), 최근 활동과 미활동 일수. 날짜를 바꿔 지난 날도 볼 수 있고, "오늘 미완료 / 미접속만 / N일 이상 미활동" 조건과 이름·학번 검색, **CSV 내려받기**를 지원합니다.
- **월별 · 학기별 통계** (왼쪽 메뉴 "📈 월별·학기별"): 월별 / 학기별을 고르면 전교·학년·반별 **완료율, 접속률, 학생당 평균 완료일, 완료 0일 학생 수, 80% 이상 완료 학생 수**를 보여 주고, 월별에서는 학년별 완료율 추이 표도 나옵니다. CSV로 내려받을 수 있습니다.
  - **운영일** = 평일(월~금) 중 테스트 반을 뺀 학생이 3명 이상 접속한 날입니다(코드의 `OPERATING_DAY_MIN_STUDENTS`). 휴일·방학은 아무도 접속하지 않아 저절로 빠집니다.
  - **완료율** = (재적 학생들이 운영일에 학습을 완료한 횟수 합) ÷ (재적 × 운영일). 접속률은 완료 또는 접속한 날로 같은 방식으로 셉니다.
  - **학기 기간**은 구글 시트의 **"학기설정"** 탭(학기, 시작일, 종료일)에서 고칩니다. 탭은 처음 불러올 때 자동으로 생기며, 안에 든 날짜(1학기 2026-08-29~2026-12-31, 2학기 2027-01-01~2027-07-31)는 예시이니 학교 일정에 맞게 바꾸세요. 날짜는 `2026-08-29` 형식으로 적습니다.
- **🍀 위클리 행운아**(왼쪽 메뉴 세 번째): 주차별·반별 당첨자 표입니다. 자세한 내용은 위 "위클리 행운아 이벤트" 항목을 보세요.
- **왼쪽 메뉴**: "출결 현황"(위 내용)과 "정기고사 → 1학기 중간 / 1학기 기말 / 2학기 중간 / 2학기 기말"이 있습니다. 정기고사 항목은 아직 "준비 중" 화면이며, 반별 응시 현황·성적은 당분간 구글 시트의 `통계_...` 탭에서 봅니다. 메뉴 목록은 `js/master.js`의 `MASTER_EXAM_MENU`에서 고칩니다.
- 테스트 반(9반)은 반 표에는 "테스트"로 표시되지만 전교·학년 합계와 명단에서는 빠집니다(코드의 `EXAM_STAT_EXCLUDE_CLASSES`).

## 명렬 대조 + 비밀번호 로그인 설정

학년·반·번호를 아무렇게나 입력해 들어오는 것을 막고, 등록된 학생만 로그인하도록 하는 설정입니다.
**"구글 시트 연동 설정"을 먼저 마친 뒤** 이어서 진행하세요.

### 1. "명렬" 시트 만들기

앱과 연결된 구글 스프레드시트에 **명렬**이라는 이름의 시트를 새로 만들고, 1행에 헤더를 넣은 뒤 우리 반 학생 명단을 붙여넣습니다.

| 학년 | 반 | 번호 | 이름 |
|---|---|---|---|
| 1 | 1 | 1 | 홍길동 |
| 1 | 1 | 2 | 김철수 |

- 이 시트에 없는 학년·반·번호는 로그인이 거부됩니다.
- **"계정"** 시트는 학생이 처음 로그인할 때 스크립트가 자동으로 만들어 관리하므로 직접 만들 필요가 없습니다(비밀번호는 원문이 아니라 해시로만 저장됩니다).

### 2. 관리자(담임) 비밀번호 설정 — 코드가 아니라 "스크립트 속성"에 저장

이 저장소는 공개 GitHub 저장소이므로, 관리자 비밀번호를 `gas/Code.gs`나 시트에 절대 적으면 안 됩니다.
대신 Apps Script 프로젝트에만 저장합니다.

1. Apps Script 편집기 좌측 **⚙️ 프로젝트 설정**을 클릭합니다.
2. **스크립트 속성 → 스크립트 속성 추가**를 누르고,
   - 속성: `ADMIN_PASSWORD`
   - 값: (선생님만 아는 관리자 비밀번호)
   를 입력한 뒤 저장합니다.
3. `gas/Code.gs`를 최신 버전(명렬 대조 코드 포함)으로 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 재배포합니다. (URL은 그대로 유지됩니다.)

### 3. "교사" 시트에 담임학급 채우기

관리자 설정 화면에서 **본인 학급만** 골라 볼 수 있도록, 시트에 **교사**라는 탭을 만들어 두세요
(자동 생성되지 않으므로 직접 탭을 만들고 아래 형식으로 채워야 합니다).

| 이름 | 부서/학년 | 직책 | 구분 | 담임학급(예: 2-1) |
|---|---|---|---|---|
| 홍길동 | 2학년 | 2학년부장 | 부장 | 2-1 |
| 김철수 |  |  | 교사 |  |

- **담임학급 칸을 `학년-반` 형식(예: `2-1`)으로 채운 사람만** 관리자 설정의 "학급 선택" 드롭다운에 나타납니다. 나머지 열(부서/학년, 직책, 구분)은 참고용이라 비워둬도 앱 동작에는 지장이 없습니다.
- 담임이 아닌 교직원도 이 시트에 함께 있어도 괜찮습니다. 담임학급 칸이 비어 있으면 그냥 목록에서 빠집니다.
- 담임 비밀번호는 여전히 학교 전체가 공유하는 하나의 `ADMIN_PASSWORD`입니다(2단계 참고). 학급 선택은 "누가 볼 수 있는지"가 아니라 "어느 반만 보이게 필터링할지"를 정하는 용도입니다.

### 4. 사용 흐름

- **최초 로그인**: 학생은 학년·반·번호 + 기본 비밀번호 **`2026`**으로 로그인합니다.
- 로그인 직후 **반드시** 새 비밀번호(4자 이상)로 바꿔야 다음 화면으로 넘어갈 수 있습니다.
- **담임 선생님이 우리 반 확인하기**: 왼쪽 사이드바 상단(또는 로그인 화면 하단) **⚙️ 관리자 설정**을 눌러 관리자 비밀번호를 입력하면, "교사" 시트에 담임학급이 등록된 선생님 목록이 뜨고 본인 이름(또는 "전체 학급 보기")을 고를 수 있습니다. 선택하면 그 반 학생들의 **마일리지, 진도율(학교 전체 최고 진도 대비 %), 최근 로그인 시각, 비밀번호 설정 여부**를 한 번에 볼 수 있고, **초기화** 버튼으로 잠긴 학생의 비밀번호를 `2026`으로 되돌릴 수 있습니다. 학생은 그 비밀번호로 다시 로그인해 새 비밀번호를 설정하면 됩니다.

> 관리자 비밀번호는 절대 학생에게 알려주지 마세요. 담임 선생님만 알고 있어야 학생이 잠겼을 때 도와줄 수 있습니다.

## 카카오톡 일일 접속 보고

학생이 로그인할 때마다 "접속로그" 시트에 기록이 쌓입니다. `?dailySummary=1` 파라미터로
이 웹앱에 GET 요청을 보내면 그 시점까지의 접속 현황을 JSON으로 돌려줍니다.
`byGrade`는 그날 학년별 순 접속 학생 수, `byClass`는 학년별·반별 순 접속 학생 수(명렬에 있는 반은 0명도 포함,
테스트 반은 접속이 있을 때만 포함), `cumulativeUniqueCount`는 서비스 시작 이후
한 번이라도 접속한 전체 누적 학생 수입니다.

```
GET <웹앱주소>?dailySummary=1
→ {"status":"ok","summary":{
     "date":"2026-10-05","uniqueCount":212,"totalCount":231,
     "byGrade":{"1":70,"2":75,"3":67},
     "byClass":{"1":{"1":9,"2":8,"3":10},"2":{"1":12,"2":11},"3":{"1":7,"2":6}},
     "cumulativeUniqueCount":540
   }}
```

테스트 계정(1학년 9반 경북 학생)으로 접속해도 이 집계에 **포함**됩니다(접속 보고를 시험해 볼 수 있도록).

매일 오전 9시 · 오후 4시에 이 값을 가져와 선생님 카카오톡(나에게 보내기)으로 전송하는 건
Apps Script가 아니라 **Claude(AI 비서)의 예약 작업**이 담당합니다. 카카오 디벨로퍼스 앱 등록이나
REST API 키, OAuth 설정 같은 건 전혀 필요 없습니다 — Claude 쪽에 이미 연결된 카카오톡 "나에게
보내기" 도구를 그대로 사용합니다.

## 정기시험 (중간시험·기말시험) — 태블릿/휴대폰 응시

중간시험·기말시험 4회(1학기 중간/기말, 2학기 중간/기말)를 학생 기기에서 직접 봅니다.
회차마다 20문항: **객관식(5지선다) 17 + 단답형 2 + 서술형 1**, 문항당 1점(총 20점).

- 문항·정답·해설은 **구글 시트에만** 있고 이 공개 저장소에는 올리지 않습니다(`worksheets/정기고사/`는 `.gitignore` 대상).
- 시험이 열리는 시간(시트의 "시험설정" 탭)에만 서버가 문항(정답 제외)을 내려주고, 채점도 서버가 합니다.
- 학생은 보기를 눌러 선택하고 다른 보기를 누르면 바뀝니다(선택한 보기를 한 번 더 누르면 해제). 제출 전에는 몇 번이든 고칠 수 있고, **제출은 학생·시험당 1회**입니다.
- 풀던 답은 자동 임시저장되어, 화면이 꺼지거나 새로고침해도 이어서 풀 수 있습니다. 종료 시각이 되면 풀던 답이 자동 제출됩니다.
- 시험 시작 전에는 왼쪽 메뉴가 "시험 예정"으로 흐리게 보이고, 시간이 되면 "응시 가능"으로 바뀝니다.

### 최초 설정 (한 번만)

1. 문항 xlsx 만들기: `worksheets/정기고사/` 에서 `python build_exam_sheet.py` → `정기시험_시트가져오기용.xlsx`
   (문항 원본은 `exam_data.py`. 정답 위치는 회차마다 자동으로 고르게 섞입니다.)
2. 구글 시트 열기 → 파일 → 가져오기 → 업로드 → 위 xlsx → **"새 시트 삽입"**.
   "시험설정", "시험문항" 두 탭이 생깁니다.
3. 구글 시트 시간대가 한국인지 확인(파일 → 설정 → 시간대: 서울).
4. `gas/Code.gs`를 Apps Script에 붙여넣고 재배포(배포 관리 → 새 버전).
5. Apps Script 편집기에서 **`시험준비`** 함수를 선택해 실행(권한 승인). "시험응시" 탭과 비밀 키가 만들어집니다.

### 시험 날짜 정하기

"시험설정" 탭에서 해당 시험의 **시작(KST)**, **종료(KST)** 칸에 `2026-10-20 08:30` 형식으로 적으면 그 시간에 열립니다
(비워 두면 닫힌 상태). 이 칸은 텍스트 서식이라 날짜로 자동 변환되지 않습니다. 앱을 다시 배포할 필요는 없습니다.

| 칸 | 설명 |
|---|---|
| 시험ID | `mid1`(1학기 중간) `final1`(1학기 기말) `mid2`(2학기 중간) `final2`(2학기 기말) — 바꾸지 마세요 |
| 공개범위 | `전체`(기본): 제출 즉시 점수 + 문항별 정답·해설 공개 / `점수`: 점수만 공개 |

### 채점과 결과 확인

- 객관식·단답형은 자동 채점입니다. 단답형은 띄어쓰기·마침표를 무시하고, 허용 답안은 `|`로 여러 개 적을 수 있습니다.
- **서술형**은 "정답" 칸의 핵심어 규칙으로 1차 채점합니다. 그룹은 `;`, 한 그룹의 유의어는 `|`로 적습니다.
  예) `서명|기한|늦;반려|접수되지|돌려` → 두 그룹에서 각각 하나 이상 들어 있고 10자 이상이면 만점·확정.
  일부만 맞으면 비율만큼 부분 점수(0.5점 단위)와 함께 **"확인필요"**로 표시됩니다.
- "시험응시" 탭에서 학생별 점수를 봅니다. 서술상태가 **확인필요**인 줄은 "서술답안"을 읽고
  **"서술점수(교사확정)"** 칸에 점수를 적으면 총점에 반영되고, 학생 화면의 잠정 표시도 사라집니다.
- 시험이 끝난 뒤 편집기에서 **`시험마감처리`**를 실행하면, 제출 버튼을 못 누른 학생의 임시저장 답안이 "자동제출"로 채점·기록됩니다.
- 문항을 고치려면 "시험문항" 탭을 직접 수정하세요(서버가 5분 정도 기억하고 있어 반영이 조금 늦을 수 있음).

### 반별 성적 통계

편집기에서 **`시험통계시트만들기`**를 한 번 실행하면 시험마다 탭이 만들어집니다
(`통계_1학기중간`, `통계_1학기기말`, `통계_2학기중간`, `통계_2학기기말`).
각 탭에는 **1학년 → 2학년 → 3학년** 순으로 학년별 표가 있고, 반별로 아래 칸이 채워집니다.

| 칸 | 설명 |
|---|---|
| 재적 | 명렬에 등록된 반 인원 |
| 응시 / 미응시 | 제출한 학생 수 / 재적 − 응시 |
| 객관식 · 단답형 · 서술형 | 반 전체 점수 합계 (서술형은 교사확정 점수가 있으면 그 점수, 없으면 자동 채점 점수) |
| 총점 | 세 가지의 합 |
| **평균(재적 기준)** | 총점 ÷ **재적 인원** — 미응시자는 0점으로 들어가므로 미응시자가 적은 반이 유리합니다 |
| **석차** | 같은 학년 안에서 평균이 높은 순서 (동점이면 같은 석차) |
| 응시자 평균(참고) | 총점 ÷ 응시 인원 |
| 서술 확인필요(건) | 아직 교사 확인 점수를 입력하지 않은 서술형 답안 수 |

각 학년 표의 맨 아래 **학년 전체** 줄에는 학년 합계와 평균이 나옵니다. 반 목록은 "명렬" 탭에 실제 있는 반으로 만들어지고(명렬이 비어 있으면 1~8반),
9반은 테스트 반으로 보고 통계 표에서 **제외**합니다(코드의 `EXAM_STAT_EXCLUDE_CLASSES`). 명렬이 바뀌면 `시험통계시트만들기`를 다시 실행하세요. 모든 칸이 시트 수식이라 "시험응시" 탭의 점수를 고치면 통계가 바로 따라 바뀝니다.

> 시험 점수는 "시험응시" 탭에만 기록되며, 학습 기록·성적 그래프(📊)와는 연동되지 않습니다.
