# 문해력 15분

특성화고(상업계열·보건행정·3D애니메이션) 학생을 위한 하루 15분 문해력 학습 웹앱입니다.
16주(주 2주제, 총 32주제 · 80일) 커리큘럼과 학생별 학습 기록(구글 시트 연동)을 제공합니다.

## 폴더 구조

```
index.html            앱 화면 뼈대
css/style.css          스타일 (라이트/다크 모드 포함)
js/config.js           구글 시트 연동 URL 등 설정
js/auth.js              학생 로그인(학년·반·번호·비밀번호)
js/admin.js              관리자(담임) 설정 — 학생 비밀번호 초기화
js/sync.js               학습 기록을 구글 시트로 전송
js/app.js                라우팅·화면 렌더링·채점 로직
data/curriculum.js       16주 커리큘럼 뼈대(주제·요일 자동 생성)
data/content/wXX.js      주차별 실제 학습 콘텐츠(단어·문제·지문)
gas/Code.gs               구글 시트 쪽에 붙여넣는 Apps Script 코드
```

## 로컬에서 열어보기

`index.html`을 브라우저로 더블클릭해서 열면 바로 동작합니다(별도 서버 불필요).

## 콘텐츠 추가하는 법

1. `data/curriculum.js`의 `TOPICS` 배열에 이미 16주×2주제 순서가 정의되어 있습니다.
2. 새 주차 콘텐츠는 `data/content/w02.js` 같은 파일을 만들어
   `var DAY_CONTENT = window.DAY_CONTENT || {}; Object.assign(DAY_CONTENT, { "w02d01": {...}, "w02d02": {...} });` 형식으로 작성한 뒤,
   `index.html`에 `<script src="data/content/w02.js"></script>` 한 줄을 추가하면 사이드바에 자동으로 반영됩니다.
3. 콘텐츠가 없는 날짜는 사이드바에 "준비 중"으로 표시됩니다.

## 구글 시트 연동 설정 (학생 학습 기록 자동 저장)

설정하지 않아도 앱은 정상 동작하며, 기록은 학생 기기(브라우저)에만 저장됩니다.
전체 학생 기록을 한 곳(구글 시트)에 모으려면 아래 절차를 따르세요.

1. 구글 드라이브에서 새 **구글 스프레드시트**를 만듭니다. (예: `문해력15분_기록`)
2. 상단 메뉴 **확장 프로그램 → Apps Script**를 클릭합니다.
3. 열린 편집기의 코드를 모두 지우고, 이 저장소의 [`gas/Code.gs`](gas/Code.gs) 내용을 그대로 붙여넣습니다.
4. 저장(Ctrl+S) 후 우측 상단 **배포 → 새 배포**를 클릭합니다.
5. 유형에서 **웹 앱**을 선택하고,
   - 실행 계정: **나(내 계정)**
   - 액세스 권한: **모든 사용자**
   로 설정한 뒤 **배포**를 누릅니다. (처음 한 번은 구글 계정 권한 승인 화면이 나옵니다.)
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/....../exec`)을 복사합니다.
7. 이 저장소의 `js/config.js` 파일을 열어 아래처럼 URL을 붙여넣고 저장·커밋·푸시합니다.

   ```js
   const APP_CONFIG = {
     SHEET_WEBAPP_URL: "여기에_복사한_웹앱_URL_붙여넣기",
     SCHOOL_NAME: "명품 경북여상 문해력 15분",
   };
   ```

8. 이후 학생이 학습을 완료할 때마다 스프레드시트의 **"기록"** 시트에 자동으로 한 줄씩 쌓입니다.
   (기록시각, 학번코드, 학년, 반, 번호, 이름, 주차, 일자ID, 영역, 주제, 유형, 점수)

> URL 설정 전에 이미 학습한 기록은 학생 기기에 "대기열"로 저장되어 있다가, URL이 설정된 이후 접속하면 자동으로 전송됩니다.

### 학생용 "내 점수 기록" 보기

화면 오른쪽 위 프로필 옆 **📊 아이콘**을 누르면 학생 본인의 점수 기록(날짜·주제·유형·점수, 평균, 꺾은선 그래프)을 볼 수 있습니다.
`SHEET_WEBAPP_URL`이 설정되어 있으면 구글 시트에서 전체 이력을 불러오고, 설정 전이거나 통신이 안 되면 이 기기에 저장된 최근 점수만 대신 보여줍니다.
(`gas/Code.gs`를 그대로 다시 배포하면 `doGet`이 `?studentId=` 조회를 지원하도록 자동으로 갱신됩니다. 이미 배포한 뒤 이 파일을 업데이트했다면 **배포 → 배포 관리 → 수정(연필 아이콘) → 새 버전**으로 다시 배포해야 반영됩니다.)

### 금요일 "행운의 7명" 이벤트

매주 금요일 아침, **그 주(월~금) 5일 학습을 모두 08:43 이전에 완료한 학생** 중 무작위로 7명을 뽑아
화면 오른쪽 위 **🎉 아이콘**에서 확인할 수 있게 하는 기능입니다. 담임 선생님이 명단을 보고 칭찬카드를 발급하는 식으로 활용하시면 됩니다.

1. `gas/Code.gs`를 최신 버전으로 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 재배포합니다. (URL은 그대로 유지됩니다.)
2. Apps Script 편집기 상단에서 함수 선택 드롭다운을 **`installWeeklyTrigger`**로 바꾸고 ▶ **실행**을 한 번만 눌러주세요. (최초 실행 시 권한 승인 창이 뜰 수 있어요.) 이 작업으로 "매주 금요일 오전 8시 50분쯤 자동 추첨"이 예약됩니다.
3. 이후 매주 금요일 아침, 스프레드시트에 **"행운의7명"** 시트가 자동으로 생기고 그 주 당첨자가 기록됩니다.
4. 학생들은 앱 상단 🎉 버튼을 누르면 가장 최근 추첨 결과를 바로 볼 수 있습니다.

> 기준 시각(08:43)이나 인원(7명)을 바꾸고 싶으면 `gas/Code.gs` 상단의 `DAILY_CUTOFF`, `WINNER_COUNT` 값을 수정한 뒤 다시 배포하세요.
> 정확한 시각 판정을 위해 스프레드시트의 시간대가 **한국 표준시(서울)**로 설정되어 있는지 확인해 주세요. (스프레드시트 메뉴 **파일 → 설정 → 시간대**)

### 학생별 요약을 보고 싶다면

"기록" 시트 옆에 새 시트를 만들고 다음과 같은 `QUERY` 수식으로 학생별 완료 횟수·평균 점수를 집계할 수 있습니다.

```
=QUERY(기록!A:L, "select B, F, count(H), avg(L) where L <> '' group by B, F label count(H) '완료수', avg(L) '평균점수'", 1)
```

## 학생 로그인 방식

**학년 + 반 + 번호 + 비밀번호**로 로그인합니다. (예: 1학년 1반 2번 → 학번코드 `1102`)
로그인 정보는 학생 기기의 브라우저에만 저장되며, 다른 학생으로 전환하려면 화면 오른쪽 위 프로필을 눌러 "다른 학생으로 전환"을 선택하면 됩니다.

`SHEET_WEBAPP_URL`이 설정되어 있지 않으면(개발/테스트) 예전처럼 대조 없이 통과됩니다.
설정되어 있으면 아래의 **명렬 대조 + 비밀번호 로그인** 방식이 적용됩니다.

## 명렬 대조 + 비밀번호 로그인 설정

학년·반·번호를 아무렇게나 입력해 들어오는 것을 막고, 등록된 학생만 로그인하도록 하는 설정입니다.
**"구글 시트 연동 설정"을 먼저 마친 뒤** 이어서 진행하세요.

### 1. "명렬" 시트 만들기

앱과 연결된 구글 스프레드시트에 **명렬**이라는 이름의 시트를 새로 만들고, 1행에 헤더를 넣은 뒤 우리 반 학생 명단을 붙여넣습니다.

| 학년 | 반 | 번호 | 이름 |
|---|---|---|---|
| 1 | 1 | 1 | 홍길동 |
| 1 | 1 | 2 | 김철수 |

- 이 시트에 없는 학년·반·번호는 로그인이 거부됩니다.
- **"계정"** 시트는 학생이 처음 로그인할 때 스크립트가 자동으로 만들어 관리하므로 직접 만들 필요가 없습니다(비밀번호는 원문이 아니라 해시로만 저장됩니다).

### 2. 관리자(담임) 비밀번호 설정 — 코드가 아니라 "스크립트 속성"에 저장

이 저장소는 공개 GitHub 저장소이므로, 관리자 비밀번호를 `gas/Code.gs`나 시트에 절대 적으면 안 됩니다.
대신 Apps Script 프로젝트에만 저장합니다.

1. Apps Script 편집기 좌측 **⚙️ 프로젝트 설정**을 클릭합니다.
2. **스크립트 속성 → 스크립트 속성 추가**를 누르고,
   - 속성: `ADMIN_PASSWORD`
   - 값: (선생님만 아는 관리자 비밀번호)
   를 입력한 뒤 저장합니다.
3. `gas/Code.gs`를 최신 버전(명렬 대조 코드 포함)으로 다시 붙여넣고 **배포 → 배포 관리 → 수정(연필) → 새 버전**으로 재배포합니다. (URL은 그대로 유지됩니다.)

### 3. 사용 흐름

- **최초 로그인**: 학생은 학년·반·번호 + 기본 비밀번호 **`2026`**으로 로그인합니다.
- 로그인 직후 **반드시** 새 비밀번호(4자 이상)로 바꿔야 다음 화면으로 넘어갈 수 있습니다.
- **비밀번호를 잊었을 때**: 왼쪽 사이드바 상단(또는 로그인 화면 하단) **⚙️ 관리자 설정**을 눌러 관리자 비밀번호를 입력하면, 반 학생별 "비밀번호 설정 여부" 목록이 뜨고 **초기화** 버튼으로 그 학생의 비밀번호를 다시 `2026`으로 되돌릴 수 있습니다. 학생은 그 비밀번호로 다시 로그인해 새 비밀번호를 설정하면 됩니다.

> 관리자 비밀번호는 절대 학생에게 알려주지 마세요. 담임 선생님만 알고 있어야 학생이 잠겼을 때 도와줄 수 있습니다.
