# 수상한 단톡방 — 새 사건 공급 가이드

학생이 하루 2사건씩 풀기 때문에, 사건이 모자라면 게임이 금방 시들해집니다. 그래서 사건을 세 갈래로 공급합니다.

| 갈래 | 누가 만드나 | 양 | 특징 |
|---|---|---|---|
| ① 오늘의 사건 | **자동 생성**(`daily.js`) | 매일 1개, 끝없이 | 날짜가 같으면 모든 학생이 같은 사건 → 친구와 답을 이야기할 수 있음. 이야기는 단순 |
| ② 정규 사건 | Claude가 쓰고 선생님이 검수 | 매주 2개 목표 | 반전·해설이 깊고, 별 3개 보상은 **처음 풀 때만** 나옴 |
| ③ 학생 제안(선택) | 학생 아이디어 → Claude가 사건으로 | 가끔 | "우리 학교 이야기" 느낌이 나서 참여가 올라감(실명·특정 가능한 상황은 빼기) |

보상은 "새 사건의 새 별"에만 붙기 때문에(같은 사건을 반복해도 마일리지가 안 쌓임), 사건이 늘수록 보상 기회도 늘어납니다.
오늘의 사건은 매일 새 id(`daily-날짜`)라서 **하루에 한 번** 별 3개 보상을 받을 수 있습니다.

## 1. 정규 사건을 만드는 법 (Claude에게 부탁하기)

Claude에게 이렇게 말하면 됩니다. (복사해서 쓰세요)

```
수상한 단톡방 정규 사건을 2개 더 만들어 줘.
- 소재: (예: 학원 알바 / 동아리 회비 / 단톡방 투표 / 배달 앱 리뷰 이벤트)
- 난이도: 쉬움 1개, 보통 1개
- 규칙은 games/chat-detective/AUTHORING.md 를 따르고,
  cases-extra.js 에 추가한 뒤 tools/check-cases.js 가 통과하는 것까지 확인해 줘.
```

선생님이 하실 일은 **읽어 보고 어색한 문장·민감한 소재만 알려 주는 것**입니다. 검사기가 "모순 쌍이 하나뿐인지"를 자동으로 확인해 줍니다.

## 2. 사건 하나의 모양

```js
{
  id: "c6", icon: "🍗", level: 2, title: "사라진 치킨 쿠폰",     // id: 영문·숫자·하이픈 30자 이하
  room: "알바방 이름", tagline: "한 줄 소개",
  people: { "점장": "👩‍💼", "하윤": "🦊", "지아": "🐹" },       // 이름: 프로필 이모지
  messages: [                                                  // 6~9개, 한 개 120자 이하
    { who: "점장", time: "오후 9:40", text: "…", claims: [{ s: "하윤", k: "퇴근 시각", v: "8시" }] },
    …
  ],
  pair: [3, 6],                  // 정답: 서로 모순되는 두 메시지 번호(0부터)
  hint: "어떤 말끼리 비교하면 되는지 살짝 알려 주는 한 줄",
  reasons: ["…", "…", "…"], answer: 0,   // "왜 수상한가" 보기 3개, answer는 정답 번호
  reveal: "진상(반전)과 따뜻하거나 웃긴 마무리",
  lesson: { words: ["근거", "추론"], text: "낱말: 한 줄 풀이" },   // 그 주 어휘와 이어 주면 좋음
}
```

### claims — 모순이 하나뿐인지 검사하는 장치
메시지가 **사실로 주장하는 것**을 `{ s: 누구/무엇, k: 항목, v: 값 }`로 적습니다.
같은 `s`·`k`에 `v`가 다른 메시지 두 개를 검사기가 "모순"으로 봅니다. 그 결과가 `pair` 하나뿐이어야 통과합니다.
예) `{ s: "민서", k: "8시 반 위치", v: "가게 밖(퇴근)" }` ↔ `{ s: "민서", k: "8시 반 위치", v: "가게 안" }`

## 3. 잘 만든 사건의 규칙

1. **정답 모순은 한 쌍뿐**: 비슷해 보여도 서로 맞는 말(함정)을 2~3개 섞어 두되, 정말 모순이 되면 안 됩니다. 검사기를 믿되 마지막엔 한 번 소리 내어 읽어 봅니다.
2. **함정은 "의심스러워 보이지만 맞는 말"**: 오래된 영수증, 전해 들은 소문, 숫자를 바르게 계산한 말 등.
3. **직접 한 말 vs 전해 들은 말**을 구분하게 만듭니다(전해 들은 말은 근거가 약하다는 배움).
4. **누구를 나쁜 사람으로 만들지 않기**: 반전은 깜짝 파티·착각·실수처럼 따뜻하거나 웃긴 쪽으로.
5. **학교 밖 소재로**: 알바, 중고거래, 친구 약속, 동아리 정산처럼 학생에게 익숙한 일상. 실제 학생·교사 이름, 특정 학교·반이 떠오르는 상황은 쓰지 않습니다.
6. **난이도 기준**: 1 = 한 사람의 말 안에서 한 항목이 바로 부딪힘 / 2 = 시각·장소처럼 한 번 계산이 필요함 / 3 = 숫자 계산이나 여러 사람의 말이 얽힘.
7. **해설(reveal)에 배움을 한 줄**: 모순은 거짓의 증거가 아니라 확인의 신호, 소문은 증거가 약함 등.
8. 이유 보기 3개는 길이를 비슷하게, 정답 위치(0·1·2)는 사건마다 고르게 섞습니다.

## 4. 올리기 전에 검사

```bash
node games/chat-detective/tools/check-cases.js
```

- 정규 사건의 구조·모순 쌍 검사 + 오늘의 사건 400일치 검사가 모두 "통과"여야 합니다.
- 실패하면 어느 사건의 어떤 점이 문제인지 알려 줍니다(예: `모순 쌍이 정답(3,6) 하나여야 하는데 0-4, 3-6 로 나와요`).

## 5. 운영 리듬

- 마스터 → **🎮 게임 참여 → 사건별** 표에서 푼 판 수, 해결률, 별 3개 비율을 봅니다.
  별 3개 비율이 80%를 넘는 사건이 많으면 더 어려운 사건(난이도 3)을 추가하고, 해결률이 30% 아래면 쉬운 사건이나 힌트를 보강합니다.
- 매주 금요일에 새 사건 2개를 추가하는 것을 기본 목표로 합니다(34주 동안 약 60개).
- 학기 초에는 쉬운 사건(난이도 1) 위주, 기말 무렵에는 난이도 3을 늘립니다.
- 오늘의 사건 소재를 늘리고 싶으면 `daily.js`의 각 유형(`makeSchedule`·`makeMoney`·`makeState`·`makeTime`) 안 소재 목록에 한 줄씩 추가하면 됩니다. 추가한 뒤 위 검사기를 돌립니다.
