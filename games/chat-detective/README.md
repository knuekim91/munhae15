# 수상한 단톡방

단톡방 대화를 읽고 **서로 모순되는 말 두 개**를 연결한 뒤, 이유를 고르면 진상이 밝혀지는 문해력 추리 게임입니다.
문해력 15분의 **상단 GAME 아이콘 / 사이드바 맨 위 "게임"** 에서 들어옵니다.

## 규칙(서버가 정합니다)
- 오늘 학습 회차를 완료한 학생에게만 열립니다(구글 시트 "기록"으로 확인).
- 하루에 **2사건**까지(해결하든 실패하든 한 판).
- **하트 점수 1~5점**: 실수·힌트 없이 풀면 5점, 실수 1번이나 힌트 1번마다 1점씩 줄어듭니다(풀었다면 최저 2점). 풀지 못해도 참여한 판은 1점. **게임에 참여하지 않으면 0점**입니다.
- 마일리지: 사건마다 **새 최고 점수**일 때만 차액 지급 — 3점 +2P, 4점 +3P, 5점 +5P(누적 기준). 같은 사건을 반복해도 더 쌓이지 않습니다.
- **랭킹**: 점수 = 사건별 최고 점수의 합. 같으면 공동 순위(1, 1, 3위). 전교/우리 반 탭, 이름은 가운데 글자를 가려 보여 줍니다. 테스트 반(9반)은 제외, 2분마다 갱신.
- 기록은 구글 시트 **"게임기록"** 탭(없으면 자동 생성)에 한 판마다 한 줄씩 쌓이고, 학습 기록·출결·위클리 행운아에는 섞이지 않습니다.
- 점수를 모으면 칭호가 올라갑니다: 🔍 수습(0) → 🕶️ 주니어(12) → 🕵️ 베테랑(40) → 🏅 명탐정(100).
- 구글 시트에 연결되지 않은 환경(내 컴퓨터)에서는 시험 모드로 기록·보상 없이 연습만 합니다.
- 보상·한도·칭호 값은 `gas/Code.gs` 맨 아래 게임 구역의 `GAME_DAILY_LIMIT`, `GAME_POINT_MILEAGE`, `GAME_TITLES`, `GAME_RANK_MASK_NAMES` 에서 바꿉니다.

## 사건 공급
`AUTHORING.md` 를 보세요. 오늘의 사건(자동 생성) + 정규 사건(`cases.js`, `cases-extra.js`) + 검사기(`tools/check-cases.js`)로 이루어집니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `game.js` | 화면과 진행 |
| `cases.js`, `cases-extra.js` | 정규 사건 데이터 |
| `daily.js` | 오늘의 사건 자동 생성기 |
| `tools/check-cases.js` | 사건 검사기(모순 쌍이 하나뿐인지 자동 확인) |
| `AUTHORING.md` | 새 사건 공급 가이드 |

관리자 화면: 담임 관리자(학생 관리)에 🎮 오늘·누적 열, 마스터에 **🎮 게임 참여** 메뉴(전교·반별·학생별·사건별)가 있습니다.
