# 수상한 단톡방 (시험판)

단톡방 대화를 읽고 **서로 모순되는 말 두 개**를 연결한 뒤, 이유를 고르면 진상이 밝혀지는 문해력 추리 게임입니다.
아직 시험판이라 문해력 15분 메뉴에는 연결하지 않았고, 주소로만 들어갈 수 있습니다.

- 주소: `/games/chat-detective/` (문해력 15분 사이트 아래)
- 점수: 별 3개(실수 1번마다 -1, 힌트 사용 -1, 기회 3번 모두 쓰면 실패). 기록은 학생 기기(localStorage)에만 저장됩니다.
- 사건 추가: `cases.js` 배열에 같은 모양의 사건을 추가하면 됩니다. 정답 모순 쌍(`pair`)은 **반드시 한 쌍뿐**이어야 하고,
  비슷해 보이지만 서로 맞는 말(떠도는 소문, 오래된 영수증 등)을 일부러 섞어 두면 더 재미있습니다.
- 사건 글에는 실제 학생·교사의 이름이나 특정할 수 있는 상황을 쓰지 않습니다.
